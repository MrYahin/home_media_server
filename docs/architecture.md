# Архитектура

## Цель

Единая домашняя медиатека на NAS, воспроизведение через Plex и панель Home Assistant с недавно добавленными материалами. После запуска просмотра — автоматизации домашнего кинотеатра.

## Схема

```text
NAS: фильмы / сериалы / музыка / домашнее видео
  | доступ по локальной сети; протокол уточняется
  v
Beelink Mini S12 Pro: Plex Media Server
  |
  +--> Клиенты Plex: телевизор / приставка / компьютер / телефон
  |
  +--> Интеграция Plex в Home Assistant: состояние и управление

Данные о недавно добавленном контенте Plex
  | источник / интеграция уточняются
  v
Recently Added Media Card на панели Home Assistant

Home Assistant --> автоматизации освещения
```

Home Assistant может работать на отдельном устройстве или на Beelink; решение пока не принято.

## Разделение ответственности

| Компонент | Назначение |
|---|---|
| NAS | Хранение медиафайлов |
| Beelink Mini S12 Pro | Вычислительный узел для Plex |
| Plex Media Server | Библиотеки и доставка контента клиентам |
| Клиенты Plex | Воспроизведение |
| Home Assistant | Панель и автоматизации |
| Recently Added Media Card | Отображение недавно добавленных материалов |
| Источник данных карточки | Получение данных для карточки; конкретное решение не выбрано |

Карточка не заменяет Plex Media Server. Не считать стандартную интеграцию Plex автоматически готовым источником данных для Recently Added Media Card: совместимую связку необходимо проверить отдельно.

## Предлагаемая организация NAS

```text
media/
  movies/
  tv/
  music/
  home-videos/
```

Это логическая структура, а не реальные пути существующего NAS. Пути подключения на Beelink определяются после выбора ОС и протокола. Для Plex предлагается отдельная учётная запись NAS с доступом только к нужным каталогам; запись разрешать лишь при явной необходимости.

## Предлагаемые сценарии

- Просмотр фильма из библиотеки Plex на телевизоре.
- Просмотр списка недавно добавленных фильмов и сериалов в Home Assistant.
- При воспроизведении на плеере гостиной — приглушить свет.
- При паузе — включить мягкое освещение.
- При завершении — восстановить освещение по согласованному правилу.
- Просмотр на телефоне не должен менять свет в гостиной.

Свет, сущности и правила восстановления ещё не определены. Запуск конкретного фильма нажатием на карточку не считается подтверждённой функцией проекта до проверки возможностей выбранной связки.

## Открытые решения

- Модель и ОС NAS, диски, свободный объём, доступные сетевые протоколы.
- Фактическая комплектация Beelink: RAM, SSD, установленная ОС.
- ОС Beelink и способ установки Plex: напрямую, контейнер или виртуальная машина.
- Место и способ установки Home Assistant.
- Точный репозиторий Recently Added Media Card, версия и поддерживаемая интеграция-источник.
- Модели клиентов Plex, форматы видео, разрешение, субтитры и число одновременных просмотров.
- Необходимость транскодирования и Plex Pass.
- Нужен ли доступ извне и каким способом.
- Место резервных копий и сроки хранения.

## Эксплуатационные требования проекта

- Сначала локальное воспроизведение, затем карточка и автоматизации, затем удалённый доступ.
- Предлагается проводное подключение Beelink и NAS к локальной сети.
- После перезагрузки доступ к NAS должен восстанавливаться до использования библиотек Plex.
- Хранить конфигурацию и служебные данные Plex отдельно от каталогов медиа; конкретные пути определить при установке.
- Не открывать сервисы в интернет без отдельного решения по доступу и защите.
- Предусмотреть отдельную резервную копию семейных материалов и конфигураций.
