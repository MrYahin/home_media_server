# План реализации

Все пункты пока являются планом, а не отчётом о выполнении. Команды установки и готовые YAML-конфигурации появятся после выбора ОС, путей и интеграций.

## 1. Инвентаризация и решения

- [ ] Уточнить модель и ОС NAS.
- [ ] Проверить RAM, SSD и ОС Beelink Mini S12 Pro.
- [ ] Уточнить, установлен ли Home Assistant и где.
- [ ] Определить устройства просмотра, типы файлов и число потоков.
- [ ] Выбрать ОС Beelink и способ запуска Plex.
- [ ] Выбрать сетевой протокол доступа к NAS.
- [ ] Найти точный проект Recently Added Media Card и проверить совместимый источник данных.

Результат: согласованная схема установки без предположений о доступном оборудовании.

## 2. Подготовка NAS и сети

- [ ] Создать или выбрать каталоги movies, tv, music, home-videos.
- [ ] Создать отдельную учётную запись для доступа Plex.
- [ ] Выдать минимально необходимые права.
- [ ] Зафиксировать адреса NAS и Beelink, например резервированием DHCP.
- [ ] Подключить каталоги NAS на Beelink выбранным способом.
- [ ] Настроить восстановление подключения после перезагрузки.
- [ ] Проверить чтение тестовых файлов от имени службы или контейнера Plex.

Результат: Beelink стабильно читает файлы NAS; реальные пути документированы, секреты не опубликованы.

## 3. Установка Plex

- [ ] Установить Plex Media Server на Beelink выбранным способом.
- [ ] Определить постоянное расположение конфигурации и служебных данных.
- [ ] Настроить автозапуск.
- [ ] Выполнить первоначальную настройку Plex.
- [ ] Создать отдельные библиотеки фильмов, сериалов и домашнего видео; музыку добавлять при необходимости.
- [ ] Добавить небольшую тестовую подборку с NAS.
- [ ] Проверить распознавание файлов и оформление библиотеки.
- [ ] Установить клиент Plex на основное устройство просмотра.

Результат: тестовый фильм из NAS воспроизводится через сервер на Beelink.

## 4. Проверка воспроизведения

- [ ] Проверить типичный фильм, файл высокого разрешения, субтитры и домашнее видео.
- [ ] Зафиксировать Direct Play, Direct Stream или транскодирование для каждого теста.
- [ ] Проверить загрузку процессора и отсутствие остановок.
- [ ] Проверить одновременный просмотр на нужном количестве устройств.
- [ ] При необходимости транскодирования проверить совместимость оборудования, ОС и условия Plex Pass.
- [ ] Повторить тест после перезапуска Beelink и NAS.

Результат: фактические форматы и число потоков подтверждены тестом, а не оценкой модели компьютера.

## 5. Home Assistant и Recently Added Media Card

- [ ] Подтвердить место установки Home Assistant; если его нет, выбрать и установить.
- [ ] Подключить интеграцию Plex Media Server для состояния и управления воспроизведением.
- [ ] Запустить видео и определить сущность плеера гостиной.
- [ ] Проверить точный репозиторий карточки, документацию и поддерживаемую интеграцию-источник.
- [ ] Установить источник данных выбранным способом.
- [ ] Установить Recently Added Media Card по документации выбранного проекта.
- [ ] Настроить карточки недавно добавленных фильмов и сериалов.
- [ ] Проверить названия, постеры, даты и доступность изображений из браузера пользователя.
- [ ] Добавить новый тестовый материал в Plex и проверить обновление карточки.
- [ ] Отдельно проверить действия при нажатии; не обещать запуск просмотра до проверки.

Результат: панель HA отображает новые материалы из реальной медиатеки. Токены и пароли не попадают в репозиторий.

## 6. Автоматизации домашнего кинотеатра

- [ ] Выбрать реальные сущности освещения и плеера гостиной.
- [ ] Воспроизведение: приглушить свет при согласованных условиях.
- [ ] Пауза: включить мягкий свет.
- [ ] Завершение: определить и реализовать возврат освещения.
- [ ] Исключить реакцию на другие Plex-клиенты.
- [ ] Проверить ручное управление, недоступность плеера и перезапуск HA.

Результат: освещение реагирует только на нужное устройство и не мешает обычному использованию комнаты.

## 7. Резервное копирование и обслуживание

- [ ] Определить отдельное место для резервных копий семейных видео.
- [ ] Настроить копирование конфигурации Plex и Home Assistant.
- [ ] Проверить восстановление тестового файла и конфигурации.
- [ ] Определить порядок обновления с возможностью отката.
- [ ] Зафиксировать порядок запуска и восстановления доступа к NAS.
- [ ] Проверить поведение при временной недоступности NAS без потери настроек библиотек.

## 8. Удалённый доступ — необязательный отдельный этап

- [ ] Решить, нужен ли просмотр вне дома.
- [ ] Выбрать способ доступа и проверить его безопасность.
- [ ] Проверить актуальные условия Plex для выбранных клиентов и удалённого просмотра.
- [ ] Провести тест вне домашней сети.

Не включать проброс портов автоматически в рамках первоначальной установки.

## Критерии готовности

- [ ] Медиатека хранится на NAS, Plex работает на Beelink Mini S12 Pro.
- [ ] Основной клиент стабильно воспроизводит согласованные тестовые файлы.
- [ ] После перезагрузки сервер снова получает доступ к NAS.
- [ ] Recently Added Media Card показывает новые материалы.
- [ ] HA видит состояние нужного плеера.
- [ ] Автоматизации не срабатывают от посторонних клиентов.
- [ ] Резервная копия важных данных существует и проверена восстановлением.
- [ ] В репозитории нет секретов.
