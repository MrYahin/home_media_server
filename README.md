# Домашний медиасервер

Проект домашней медиатеки на базе Plex и Home Assistant.

## Согласованные решения

- Компьютер: Beelink Mini S12 Pro.
- Хранилище медиафайлов: отдельный NAS-сервер.
- Plex Media Server планируется разместить на Beelink.
- Home Assistant: интерфейс и автоматизации. Место установки пока не выбрано.
- Recently Added Media Card: выбранная карточка недавно добавленных материалов в Home Assistant. Источник данных и совместимость версий ещё нужно проверить.
- Просмотр: приложение Plex на телевизоре, приставке, компьютере или телефоне.

## Статус

Этап проектирования. Документация фиксирует договорённости и предлагаемый порядок работ, а не подтверждает выполненную установку. ОС, протокол доступа к NAS, источник данных карточки и место установки Home Assistant не утверждены.

Не публиковать пароли, Plex-токены, ключи VPN и другие секреты в репозитории.
